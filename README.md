# 中文打字競速

多人連線的中文打字競速網站。開房間、分享連結、朋友加入，同步倒數後一起打同一篇文章，
依完成時間排名。不需要註冊帳號，瀏覽器就能玩。

線上版本：<https://pangc-zhtw-typecomp.onrender.com>

## 遊戲規則

- 所有玩家打同一篇文章
- **必須完全打對才算完成**，所以正確率永遠是 100%，排名直接比時間
- 只看最終結果：過程中打錯再用 Backspace 改掉，不扣分
- 速度以 CPM（字/分鐘）呈現
- 半形標點（`,` `.` `!` `?`）會自動視為對應的全形標點，空白與換行一律忽略
- 沒有時間限制：所有人都完成就自動結算；有人完成後，房主也可以隨時按「結束比賽」
- 未完成的玩家排在完成者之後，依進度（連續正確字數）多寡排序
- 比賽中的計時塔依名次即時排序，超車時那一列會滑到新位置並閃一下綠色（最多每秒重排一次，不會一直抖）

### 連續多局與勝場

- 結算後房主可以按「再來一局」：從同一個分類抽新文章，直接倒數，不用回 Lobby
- 每局的第一名記一勝
- 第二局起，結果畫面會多一張累計勝場表；Lobby 的玩家旁也會顯示目前勝場
- 房主可以在 Lobby 按「重設勝場」歸零；中途加入的人從 0 勝開始
- 房主可以在 Lobby 按玩家旁的「踢出」把人請出房間；對方之後還能用連結回來，但會是新玩家

### 個人紀錄

- 每局記錄自己的速度、打錯次數，以及打錯時原本該打的字
- 結果畫面顯示本局統計，打破個人最佳會提示
- 首頁的「我的紀錄」顯示累計局數、最佳速度、近 20 局平均、最常卡住的字
- 只存在這台電腦的瀏覽器（localStorage），不會上傳到伺服器

## 本機開發

第一次要先建虛擬環境並安裝套件：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

之後每次啟動（`DEV_PASSWORD` 是開發者專區的密碼，本機隨便設一個就好）：

```powershell
$env:DEV_PASSWORD = "dev1234"
.\.venv\Scripts\python.exe -m uvicorn server.main:app
```

開 <http://127.0.0.1:8000>。改完 `.py` 要按 Ctrl+C 再重新啟動；前端檔案（`static/`）改完重新整理網頁就好。
（不建議加 `--reload`：在 Windows 上只要瀏覽器還連著，自動重啟常會卡住，結果還在跑舊程式。）
要測多人就開好幾個分頁 —— 身分存在 `sessionStorage`，每個分頁是獨立的玩家。

### 跑測試

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt   # 第一次才需要
.\.venv\Scripts\python.exe -m pytest
```

`tests/` 裡的整合測試會自己在隨機 port 啟動一個伺服器，用 WebSocket 模擬多位玩家，
測多局勝場、結束比賽、踢人、重連、換房號與開發者 API。改完程式跑一次，確認舊功能沒壞。

## 部署

程式碼推上 GitHub 之後，Render 會自動偵測並重新部署：

```powershell
git add .
git commit -m "說明這次改了什麼"
git push
```

Render 上的設定：

| 欄位 | 值 |
| --- | --- |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn server.main:app --host 0.0.0.0 --port $PORT` |
| Environment → `DEV_PASSWORD` | 開發者專區的密碼，請設夠長的；可以用逗號分隔多組（例如 `aaa111,bbb222`），任一組都能登入；每組前面加「名字:」（例如 `小明:aaa111,小美:bbb222`）登入後會顯示「嗨，小明」；不設的話專區停用 |
| Environment → `DEV_PROFILES` | （選填）開發者專區歡迎列的副標與頭像，格式 `名字\|副標\|頭像圖片網址`，多人用分號隔開，例如 `小明\|主要開發者\|https://github.com/xiaoming.png;小美\|文章庫維護`；名字要跟 `DEV_PASSWORD` 裡的一樣 |

`--host 0.0.0.0` 和 `--port $PORT` 都是必要的：容器裡必須聽所有來源，
而 port 號由平台透過環境變數指定，不能寫死。

免費方案閒置 15 分鐘會休眠，下一個人連進來要等約 30 秒冷啟動。

## 開發者專區

首頁右下角的「開發者專區」小卡片（`/dev.html`），輸入 `DEV_PASSWORD` 的密碼進入：

- **伺服器狀態**：運作時間、房間數、在線人數、每間房間的狀態與玩家，每 3 秒更新；可以強制關閉房間，或幫房間換房號（例如改成好記的 `TEST`）。
  換房號後房裡的人會自動跟上；舊房號只給當下斷線的人重連用，拿舊連結的新玩家進不來
- **機器人對手**：對指定房號加入機器人，設定速度後會跟真人一樣倒數、打字、算排名，一個人就能測多人功能
- **全站公告**：送一則訊息給所有在線玩家
- **設定**：即時調整房間人數上限、倒數秒數等，只存在記憶體，重啟後回到 `config.py` 的預設值
- **重新載入文章庫**：改完 `data/articles.txt` 不用重啟伺服器
- **房主權限**：展開任何一間房間，房主能做的事開發者都能做：開始／再來一局、結束比賽、回 Lobby、換文章分類、重設勝場、踢人（包括房主本人，會自動交棒）。開發者結束比賽不用等有人完成
- **介面設計**：「全站設計」決定所有玩家看到的樣子（預設是賽事計時看板，可切回原始版）；「只在我的瀏覽器預覽」用來試新設計，其他人看不到。全站設計重啟後回到 `config.py` 的 `SITE_DESIGN`

## 檔案結構

```
server/
  main.py      FastAPI 進入點，WebSocket 收發與訊息分派
  rooms.py     房間／玩家狀態機：加入、斷線重連、房主交棒、比賽流程
  scoring.py   正規化、進度計算、完成判定、CPM
  texts.py     讀取內建文章庫
  dev.py       開發者專區 API 與測試機器人
  config.py    所有可調參數
data/
  articles.txt 內建文章，純文字檔
static/
  index.html   四個畫面：進入、Lobby、比賽、結果
  app.js       連線、自動重連、IME 處理、畫面渲染
  style.css    樣式（支援淺色／深色模式）
  theme.js     亮暗切換與載入介面設計（兩個頁面共用）
  designs/     介面設計，蓋在 style.css 上面（timing.css = 賽事計時看板）
  dev.html     開發者專區
  dev.js       開發者專區的畫面與 API 呼叫
```

房間狀態全部放在記憶體，所以伺服器重啟時所有房間會消失，而且只能跑單一個 process。
第一版夠用，要擴充再換 Redis。

## 增減文章與分類

編輯 `data/articles.txt`：

```
== 古文15 ==
---
第一篇文章…
---
第二篇文章…

== 白話文 ==
---
第一篇文章…
```

- `== 名稱 ==` 開一個新分類，房主在 Lobby 可以從下拉選單挑
- 同一分類裡，每篇文章之間用一行 `---` 分隔
- 以 `#` 開頭的行是註解
- 一篇文章可以斷成好幾行寫，載入時會自動接成一整段
- 標點請用全形，建議長度約 100 字

還沒有文章、只想先在選單裡預告的分類，寫在 `server/config.py` 的
`UPCOMING_CATEGORIES`，會顯示成不可選的項目。等真的寫好文章就把它從那裡刪掉。

改完 `git push` 就會生效。本機開發時，改完文章要重啟伺服器，
或到開發者專區按「重新載入文章庫」。

## 版本號

寫在 `server/config.py` 的 `VERSION`，網頁標題旁和開發者專區都會從伺服器讀取顯示。
發布新版時改這裡就好。

## 調整規則

全部集中在 `server/config.py`：房間人數上限、倒數秒數、
斷線寬限秒數、自訂文章長度限制。
